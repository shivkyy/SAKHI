Live Tracking Gateway

System Status: Operational

This secure microservice coordinates real-time emergency telemetry for the SAKHI physical wearable and Android application.

Emergency Tracking Protocols

  • ✓
    Access-Controlled Tracking: Live tracking links require a cryptographically generated reader token embedded in the emergency SMS dispatch.
  • ✓
    Writer Authentication: Only the authenticated Android client possessing the private writer key can publish location updates.
  • ✓
    Real-Time SSE Streaming: Trusted contacts view real-time location breadcrumbs and updates via Server-Sent Events without polling lag.
  • ✓
    Privacy & Retention: Emergency sessions expire automatically after 2 hours and all session telemetry is purged within 24 hours.

Backend API Verification

GET /health → System status & active session count
POST /api/sessions → Create emergency tracking session
POST /api/sessions/:id/location → Upload live GPS update
GET /api/sessions/:id/stream → Real-time SSE stream for viewers
